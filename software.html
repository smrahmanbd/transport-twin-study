Choosing

How to choose between tools

Standards and APIs

Prefer tools that read and write the open standards your partners use (GTFS-Realtime, DATEX II, NGSI-LD, IFC 4.3). Ask for a documented API in every contract.

Licensing and lock-in

Commercial simulators bring support and validated models. Open source brings control and no licence fees. Many agencies mix them: open data layers, a commercial simulator.

Data location

Movement and video data are personal data. Check where cloud services store and process it, and what local law requires (for example the EU GDPR or Saudi Arabia’s PDPL).

Real-time performance

Test the full loop’s latency with realistic load before buying. A simulator that runs faster than real time on a corridor may not on a city.

Skills

Count the people who can maintain each tool after the pilot. Python, SQL and one simulator cover most needs.

Security

Anything that can change a signal or a timetable needs authentication, network separation and audit logs. IEC 62443 and the NIST Cybersecurity Framework are common references.

Tool names are examples, not endorsements. Versions and licences change; check each vendor’s current terms.
